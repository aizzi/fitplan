# Fitplan App's Requirements

In the following we will use the `MoSCoW` framework to classify requirements:

- **MUST** : The requirement is mandatory and must be satisfied by one or more use cases.
- **SHOULD** : The requirement is important but not mandatory.
- **COULD** : The requirement is optional.
- **WONT** : The requirement will **NOT** be satisfied.
